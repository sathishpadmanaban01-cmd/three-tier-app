# three-tier-starter

Starter scaffold for a 3-tier web application on AWS using:
- React + Vite frontend
- Python FastAPI backend
- Python Kafka worker
- MongoDB Atlas
- Redis
- Kafka
- GitHub Actions CI
- Argo CD GitOps CD
- AWS EKS with Terraform
- Prometheus, Grafana, OpenTelemetry, Elasticsearch, Kibana

This is a practical starter kit, not a finished production system.
